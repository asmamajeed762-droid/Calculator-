Scientific Calculator

A feature-rich scientific calculator that works in three modes: Python GUI, Python Terminal, and Web Browser.

File| Description

"index.html"| Web Calculator built with HTML, CSS, and JavaScript

Features

- Basic Operations: Addition, subtraction, multiplication, division, and modulus.
- Trigonometric Functions: sin, cos, tan, and their inverse functions.
- Logarithmic Functions: Natural logarithm (ln) and common logarithm (log).
- Square Root: Calculate square roots.
- Power Functions: Calculate squares (x²) and powers (xʸ).
- Factorial: Calculate factorials (n!).
- Mathematical Constants: Pi (π) and Euler's number (e).
- DEG / RAD Mode: Switch between degrees and radians.
- Memory Functions: MC, MR, M+, and M−.
- Previous Answer (Ans): Reuse the previous calculation result.
- Calculation History: Review previous calculations.
- Keyboard Support: Perform calculations using keyboard shortcuts.
- Safe Expression Parser: Evaluate mathematical expressions without using "eval()".

Technologies Used

- Python 3: Calculator logic and mathematical operations.
- Tkinter: Graphical user interface for the Python GUI calculator.
- HTML5: Structure of the web calculator.
- CSS3: Styling and layout of the web calculator.
- JavaScript: Interactive calculations in the browser.

How to Run

1. Python GUI Calculator

Requirement: Python 3

Run the following command:

python scientific_calculator_gui.py

If the command does not work, try:

python3 scientific_calculator_gui.py

2. Python Terminal Calculator

Run the following command:

python scientific_calculator.py

- Type "help" to view available commands.
- Type "exit" to close the calculator.

3. Web Calculator

- Open the "index.html" file in your browser.
- Installation: Not required for local use.
- Internet Connection: Not required for local use.

Keyboard Shortcuts

Key| Function
"0–9"| Enter numbers
"."| Enter a decimal point
"+ - * /"| Perform basic operations
"^"| Calculate powers
"!"| Calculate factorials
"%"| Perform modulus operations
"Enter"| Calculate the result
"Backspace"| Delete the last character
"Esc"| Clear all input
